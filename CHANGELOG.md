# Changelog

## v0.1.1

- Removed the activation shake and all position and size pulsing. Orange, red, and sustained Stim Mode now pulse in brightness. Green and yellow have static colors.
- Made the activation chime opt-in with `/stim sound` and saved the preference.
- Added `/stim scale [value]` with a saved 0.5–2.0 scale and a brief preview. The main text and timer scale around the saved display position.

## v0.1.0

- Added jump and rotation scoring, combat suppression, and passive decay.
- Added floating intensity text, saved placement, and sustained Stim Mode with an inactivity timer and saved longest streak.
- Added slash commands for testing, positioning, resetting, and viewing statistics.
